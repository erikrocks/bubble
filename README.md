# Bubble

A pixel-art game. Blow a bubble off a kid's wand and ride the wind down a street
that never stops getting harder.

**Live:** https://bubble.eriksheridan.com

Hold to blow — the longer you hold, the bigger the bubble. Let go to launch, hold
again for wind. Big bubbles drift and forgive; small ones drop fast and turn on a
dime. Too high and it pops; linger up there and a pigeon comes for you.

Everything is drawn procedurally into a single pixel buffer — there are no image
files anywhere in this repo, and no build step. `index.html` is the whole game.
